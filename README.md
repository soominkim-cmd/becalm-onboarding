# BeCalm 온보딩 · 메일 연결

Figma 파일 **Becalm** / Page 1 / `온보딩` 프레임(node `1:1792`, 393 × 852)을 구현한 화면입니다.
빌드 도구나 패키지 설치 없이 HTML, CSS, JavaScript만으로 동작합니다.

## 실행

```bash
python3 -m http.server 5173 --directory .
```

브라우저에서 http://localhost:5173 을 엽니다.

## 동작

- Gmail, Outlook 카드를 눌러 하나 이상 선택하면 "선택한 메일 연결하기" 버튼이 활성화됩니다.
- 다시 누르면 선택이 해제됩니다.
- 연결 버튼과 건너뛰기는 지금은 안내 메시지만 띄웁니다. 실제 OAuth 연결은 `main.js`의 연결 버튼 핸들러에 붙이면 됩니다.

## 화면 모드

- 폭 520px 이상, 높이 900px 이상: Figma 프레임 크기의 기기 틀과 목업 상태 바를 보여줍니다.
- 그보다 작은 화면(실제 모바일): 전체 화면으로 표시하고, OS 상태 바와 겹치지 않도록 목업 상태 바는 숨깁니다.

## 디자인에 없던 부분

Figma에는 선택된 상태와 활성 버튼이 없어 다음 기준으로 추가했습니다.

- 선택된 카드: 팔레트의 브랜드 블루(`#4A7AF7`) 테두리와 체크 원
- 활성 버튼: 다른 온보딩 화면의 "다음" 버튼과 같은 흰 배경, 네이비 글자

## 파일

- `index.html` 마크업
- `styles.css` 스타일과 디자인 토큰
- `main.js` 선택 상태와 버튼 동작
- `assets/` Figma에서 내려받은 로고, 체크, 페이지 표시, 상태 바 에셋
